# Image Tools

**Image Tools** is a lightweight desktop utility suite designed to simplify everyday image-related tasks.

The application brings several practical tools together in one convenient interface, providing an easy way to work with images, organize datasets, detect duplicate files, and convert documents and image formats.

Image Tools is designed with a focus on simplicity, efficiency, and compatibility. It does not require a complicated installation process and can run even on older Windows computers.

## Included Modules

The current **Version 0.90** includes the following utilities:

### 1. Dataset Worker
A tool for preparing and processing image datasets. It helps organize images and perform common dataset preparation tasks. The module is currently under development and will be included in the next version.

### 2. Find Duplicate Image
A tool for detecting identical and visually similar images. It groups similar files together and provides a convenient interface for reviewing and managing duplicates.

<img width="1399" height="930" alt="duplicate_image_main" src="https://github.com/user-attachments/assets/7ff2bb32-e4e0-4dd0-bae1-5311f1bc222a" />

### 3. PDF To Images
Converts PDF documents into individual image files. Supports configurable DPI settings and saves the resulting images in organized folders.

### 4. Image Converter and resolution changes
Converts images between popular formats, including JPEG, PNG, WEBP, BMP, and TIFF. Provides format-specific conversion options and image processing settings.
You can change the resolution of all images in a selected folder in batches (in bulk).

## Installation

Image Tools is distributed as a portable application. No traditional installation is required.

1. Download the `ImageTools.zip` archive.
2. Extract the archive to any folder on your disk.
3. Open the extracted folder.
4. Run `ImageTools.exe`.

That's it! The application is ready to use.

You can move the extracted folder to another location whenever you need to. No installation wizard or additional setup is required.

## System Compatibility

- **Operating System:** Windows
- **Architecture:** 64-bit Windows
- **Distribution:** Portable application
- **Hardware:** Designed to work on a wide range of hardware, including older systems based on Intel Socket 775 processors.

The application focuses on practical functionality without requiring modern high-performance hardware.

## Project Status and Future Development

The project is actively evolving, and new utilities, improvements, and additional functionality may be introduced over time.
